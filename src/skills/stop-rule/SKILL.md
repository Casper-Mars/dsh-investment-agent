# 止损纪律（stop-rule）

当**某标的**的价格逼近或跌破止损线时，按纪律执行减仓 / 控制仓位，**保住本金优先**。止损阈值一律**遵循该标的策略文档**（可用 `strategy_get` 读取），本 skill 不硬编码任何数值。

> 若该标的**尚无策略文档**，先按 `strategy-authorship` 的方法论生成首版。

## 两条止损线（各自从该标的配置读取）

| 止损类型 | 触发含义 | 阈值来源 | 对应仓位动作 |
|----------|----------|----------|--------------|
| **硬止损** | 价格跌破**硬止损线**：说明判断已明显走坏 | 该标的策略文档的硬止损阈值 | **控制仓位**（按配置减仓 / 降至安全仓位），防止亏损扩大 |
| **趋势止损** | 价格跌破**趋势止损线**：说明趋势已破坏 | 该标的策略文档的趋势止损阈值 | **考虑清仓**（按配置退出该标的） |

> 两条线的具体数值均**遵循该标的策略文档**（可用 `strategy_get` 读取）；不同标的阈值不同，不得互相套用。

## 处理流程

1. **识别标的**：确认触发的是**哪一个标的**（逐标的独立，不影响其它标的的持仓判断）。
2. **读数**：遵循该标的策略文档读取硬止损阈值与趋势止损阈值（可用 `strategy_get`）。
3. **比对**：用该标的当前价与两条线比对，判断所处状态：
   - 未触及 → 不动作，正常持有。
   - 跌破 / 逼近**硬止损线** → 执行「控制仓位」动作。
   - 跌破**趋势止损线** → 执行「考虑清仓」动作。
4. **给动作**：输出风险提示 + **针对该标的**的建议仓位动作。

## 输出

- **风险提示**：说明触发了哪条线、为什么危险（结合趋势与量价）。
- **建议仓位动作**：明确针对**该标的**的操作方向与幅度（减仓 / 控制仓位 / 清仓 / 继续持有），幅度按该标的配置。
- **依据**：引用读取到的该标的阈值作为判据（数值来自配置，不在此复述具体数字）。

## 纪律

- **止损是纪律，不是预测**：触发即执行，不因「再等一等」而拖延。
- **逐标的独立**：A 标的触发止损，**不**构成对 B 标的的动作理由。
- **网格让位**：若网格（`grid-strategy`）仍在生效但价格触及止损线，**止损优先**，网格先撤。
- **只做建议**：最终卖出由用户离线执行，你产出的是建议与依据。
