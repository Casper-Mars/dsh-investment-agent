# 策略创作（strategy-authorship）

指导 agent 如何为**单个标的**生成与迭代**策略文档**。策略文档是**per-symbol 的文本实体**（Markdown 文档），由 agent **生成与维护**，不是外部输入；它承载该标的的研判与操作依据，日常研判与决策**一律遵循**它。

## 定位：策略是 agent 自建并维护的标的级文档

- 策略**按标的独立**：每个标的各自一份，互不套用；A 标的的策略不得搬到 B 标的。
- 策略由**你（agent）生成与迭代**：首版凭自身经验设定，复盘后由你修订，**不依赖用户输入**。
- 策略是**决策依据**：日常研判（方向 / 区间）、网格、止损、仓位等，一律遵循该标的策略文档（可用 `strategy_get` 读取）。

## 何时写 / 何时迭代

| 场景 | 动作 |
|------|------|
| 为某标的**首次**生成策略 | 写**首版**（纯凭经验，结合相关 skill 方法论设定） |
| 复盘结论要求调整策略 | 以**新版本**迭代（`strategy_set`，附 `rationale`） |

- **首版**：标的须已建立（`ledger_init`）；无需历史对照，凭经验 + 方法论直接写出。
- **迭代**：复盘（`review_*`）发现策略失配（如方向命中率偏低、连续未命中、区间失守）时，修订策略并写新版本。

## 应包含什么

策略文档正文（自然语言）应覆盖该标的的以下维度（**标的无关**，具体数值由 agent 按标的设定，不在此写死）：

| 维度 | 说明 |
|------|------|
| 关注维度 | 该标的研判时要看的指标 / 形态 / 板块联动等 |
| 强弱分区 / 震荡区间 | 弱势区 / 震荡区 / 强势区的分界，及震荡区间 `[低, 高]` |
| 网格参数 | 网格档数、网格间距、每档数量（供 `grid-strategy` 用） |
| 止盈 / 硬止损 / 趋势止损 | 止盈边界、两条止损线的触发与动作（供 `stop-rule` 用） |
| 风险纪律 | 仓位上限、越界不加仓、防守优先等纪律 |
| 检讨阈值（可选） | 机器可读的检讨阈值，写在前置 front-matter（见下） |

## 结构化段语法（front-matter）

需要机器读取的数值写在文档**顶部 YAML front-matter**（`---` 包裹），正文写自然语言：

```yaml
---
thresholds:
  dir_hit_min: <方向命中率下限，比例值>
  cum_return_min: <累计收益率下限>
  miss_streak_max: <连续未命中次数上限>
---
```

- 键名为**蛇形**：`dir_hit_min` / `cum_return_min` / `miss_streak_max`。
- `thresholds` 会被 `getThresholds` 读取，用于复盘检讨（`review_retrospect`）的劣化判定；**缺省（或非法键）回落默认值**。
- 正文其余内容写自然语言，供 agent 与用户阅读；**不把机器阈值散落在正文**。

## 如何迭代（版本不可变）

复盘后调整策略时，以**新版本**写入（`strategy_set`）：

- **版本不可变**：每次 `strategy_set` 都产生新版本，历史版本只读、不可覆盖，可回读对照。
- **必带 `rationale`**：每次写入都要给出**为什么这么改**（复盘结论 → 变更点 → 预期效果）。
- **非首版必带 `parent_version`**：指向上一版，保留演化链；首版省略 `parent_version`。
- 历史版本可用 `strategy_get` 指定版本号读回，对照「当时的设定与事后表现」。

## 与感知程序联动

策略变化后，**复核感知程序是否失配**：

- 若感知脚本仍按旧策略的维度 / 阈值采集与判断 → 失配，需按 `sense-authorship` 的方法论更新感知程序，走 `sense_archive_commit`（`keep` / `patch` / `replace`）。
- 若策略未改变感知所需维度 → `keep`，不动感知程序。
- 联动顺序：**先定策略，再对齐感知**；策略是感知的依据，感知服务于策略。

## 反例 / 红线

- **不**写死某个标的的**具体价格 / 阈值常量**（不硬编码某价位、某百分比）；具体数值由 agent 按标的设定并写入该标的自己的策略文档，而非写进本 skill 或其它 skill。
- **不**把 A 标的的策略套用到 B 标的；每个标的独立一份。
- **不**绕过 `strategy_set` 直接改文件；版本登记必须经策略工具落库，保证 current 指针与历史版本一致、可回滚。
