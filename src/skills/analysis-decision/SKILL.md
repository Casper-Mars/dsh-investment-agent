name: analysis-decision
description: 对某标的做分析与决策：技术面研判 + 消息面/资金面/全球视角，综合给出方向、数量与价位。分析与决策的方法论，可随复盘迭代进化。
whenToUse: 收到感知汇报、需对某标的做出研判并给出买卖/仓位决策时（统筹 trend/grid/stop 三战术 skill）。
---

定位：分析与决策的**上层方法论**（可进化），统筹底层战术 skill，产出该标的的最终决策。
- 先研判（信号真伪 / 方向 / 区间），再决策（买卖 / 仓位 / 价位），最后给依据与置信度。

输入：该标的行情上下文、消息面/资金面线索、全球市场背景、该标的策略文档（strategy_get）。

研判框架（多因子综合，而非单一指标）：
- 技术面：调用 trend-analysis 判方向/区间/信号真伪；sideways 时转 grid-strategy。
- 消息面/资金面：新闻、公告、板块资金流向，识别催化与情绪（主动用任务程序采集，交叉验证）。
- 全球视角：以港股/美股/大宗/汇率/宏观为参照，判断 A 股的相对位置与外部扰动。
- 信号 / 噪音 / 正常波动三分：不因单点异动误判方向。

决策输出（对齐工作流第 4 步）：
- 方向（buy/sell/hold/reduce）+ 数量 + 参考价位 + 依据 + 置信度（0-1）。
- 触达止损/止盈边界时，调用 stop-rule 给仓位动作。
- 每一项均遵循该标的策略文档（区间/网格/止损阈值），不套用他标的数值。
