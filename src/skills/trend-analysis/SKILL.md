# 趋势研判（trend-analysis）

对**单个标的**研判当前趋势方向、震荡区间与置信度，回答一个问题：**此刻的变化，是信号、噪音，还是正常波动？**

## 输入

研判前先收集该标的的以下信息（缺项要说明，不要臆造）：

| 维度 | 内容 |
|------|------|
| 标的 | `symbol`（代码 / 名称，ETF 与 A 股一视同仁） |
| 价 | 最新价、涨跌幅、日内高低 |
| 量 | 成交量 / 量比，及相对近期的放缩量情况 |
| 均线 | 短中期均线的位置关系、排列与斜率 |
| 板块联动 | 所属板块 / 关联指数的同向或背离 |
| 分时 | 分时形态、均价线关系、尾盘表现 |
| 策略配置 | **该标的**的策略配置：弱势区 / 震荡区 / 强势区的分界与趋势判定阈值 |

> 所有区间与阈值一律**从该标的策略配置读取**，不同标的可以不同；本 skill 不预设任何具体数值，也不要把某一标的的数值套用到另一标的。

## 输出

研判结果按固定四段输出：

- **【方向】** `up` / `down` / `sideways`
  - `up` / `down` 仅当**方向明确**时给出；不明确一律 `sideways`。
- **【区间】** `[低, 高]`：该标的当前有效波动区间，取自**该标的策略配置**的对应区间（弱势区 / 震荡区 / 强势区）。
- **【置信度】** `0-1` 的小数：对本次方向判断的把握程度（越接近 1 越有把握；把握不足时如实给低值）。
- **【关键观测点】**：接下来决定判断是否成立的最重要 1-3 个观测点（例如：某均线能否守住、某区间边界能否放量突破、板块是否同向），用于后续复验。

## 研判准则（趋势跟随）

- **只做明确趋势**：`up` / `down` 必须有**均线结构 + 量价关系**的共同确认；仅凭单根 K 线、单点异动或盘口噪音不足以定性。
- **震荡判定优先**：当方向未获明确确认时，判为 `sideways`，并转入网格思路（见 `grid-strategy`），而不是强行赌方向。
- **信号 / 噪音 / 正常波动**三分：
  - **信号**：有量价与结构支撑、方向可能改变 → 提高置信度并给出方向。
  - **噪音**：幅度小、无结构配合、快速回归 → 判为正常扰动，维持原方向判断。
  - **正常波动**：在区间内往复、未触及边界 → 维持现有判断，不动作。
- **板块联动校验**：优先采信与板块 / 指数同向的走势；孤立异动要降权。
- **ETF 与 A 股通用**：同一套流程适用于 ETF 与个股；差别只在各自策略配置的阈值与区间，不在方法。

## 与其它 skill 的衔接

- 判定为 `sideways` → 交给 `grid-strategy` 生成网格买卖点。
- 价格逼近 / 跌破止损线 → 交给 `stop-rule` 给出仓位动作。
- 感知维度不足以支撑研判 → 按 `sense-authorship` 调整感知脚本。
